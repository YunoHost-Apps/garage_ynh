**Before installing** your Garage node:
* We suppose that there are no personalized mounting points on your YunoHost system, specifically for `/home/yunohost.app/`
* Otherwise, prefer manually mounting Garage Data and Metadata partitions and type `manual` in the data and metadata fields of the install form
* Please read instructions carefully before installing, notably [Garage configuration depending on your server setup](https://github.com/YunoHost-Apps/garage_ynh/blob/master/doc/ADMIN.md#configuration-depending-on-your-server-setup)
