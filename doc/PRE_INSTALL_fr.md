**Avant d'installer** votre noeud Garage :
* On supposera qu'il n'y a pas de point de montage personnalisé pour le système YunoHost, et en particulier pour `/home/yunohost.app/`
* Sinon, optez pour un montage manuel des partitions data et metadata en tapant `manual` dans les champs data et metadata du formulaire d'installation
* Lisez impérativement les instructions avant d'installer, surtout la [Configuration de Garage en fonction de votre type de serveur](https://github.com/YunoHost-Apps/garage_ynh/blob/master/doc/ADMIN_fr.md#configuration-en-fonction-de-votre-type-de-serveur)
